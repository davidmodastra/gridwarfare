## 🛠️ Tecnologías

Actualmente el proyecto utiliza:

- HTML5
- CSS3
- JavaScript
- JSON (configuración y almacenamiento de datos del juego)
- Python (herramientas de desarrollo, optimización y automatización)
- Servidor Linux para alojamiento y pruebas

Próximamente:

- Unreal Engine 5
- Blueprints
- C++


## ✨ Características actuales

- 🎯 Shooter 2D rápido y dinámico.
- 🌍 Biomas diferentes.
- 👑 Zonas con jefes.
- 💥 Efectos visuales.
- 📱 Compatible con dispositivos móviles.
- 🎮 Joystick táctil para móviles.
- 🗺️ Minimap.
- ❤️ Sistema de vida y escudo.
- 🔫 Múltiples armas.
- ⚔️ Sistema de rondas progresivas.
- 👾 15 enemigos por ronda.
- 📈 Dificultad creciente.
- 🏆 Animación de victoria al completar las 10 rondas sin morir.
- ⚙️ Menú de configuración.
- 📂 Configuración y datos del juego mediante archivos JSON.
- 🐍 Scripts en Python para optimización, automatización y herramientas internas del proyecto.
